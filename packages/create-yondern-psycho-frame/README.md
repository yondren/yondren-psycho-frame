# create-yondern-psycho-frame

[yondern-psycho-frame](https://www.npmjs.com/package/yondern-psycho-frame) 的
npm create 入口包。`npm init yondern-psycho-frame` / `npm create yondern-psycho-frame`
会解析到本包并转发参数给核心包的 `init` 命令。

```sh
npm create yondern-psycho-frame@latest my-project
```

等价于 `npx yondern-psycho-frame init my-project`。命令、配置与模板说明见
[yondern-psycho-frame](https://www.npmjs.com/package/yondern-psycho-frame)。
