# 舰队模式（fleet）

舰队模式是 `workMode.fleet=on` 时的会话内委派纪律：主线程当指挥，把可独立切分的批量工作交给
子代理并行执行，自己留决策与验收；语义真源见 [development.md](../development.md)。

## 什么时候用

用：批量、检索、整理、提取、分类等明确重复、切片间无共享写目标的工作；不用：闲聊、单点查找、
架构决断、切片间强依赖的工作——协调成本超过工作本身时留在主线程。`fleet=on` 不等于必须派发，
派不派看收益是否超过协调成本。

## 派发包

派发前写清以下各项，写不全就别派：

- Outcome：交付什么，验收标准是什么。
- Benefit：为什么值得一个子代理，而不是主线程顺手做。
- Sources：只读哪些事实源。
- Scope：允许改哪些文件；一个共享写目标同时只有一个写者。
- Checks：子代理自己必须先过的检查。
- Stop when：什么情况下停下来问。
- Return：结论 + 证据路径，不返回过程。

## 收口

1. 只并行真正独立的切片；有依赖的顺序执行。
2. 返回后核验真实产物（文件、命令输出、链接），不盲信汇报。
3. 子代理报错或被打断时，先看共享产物有无可用成果，再决定重试。
4. 架构决策与最终验收留在主线程。

## 与 worktree 的分层

舰队模式管会话内拓扑，[parallel-worktrees.md](parallel-worktrees.md) 管任务间互不共享
checkout；两层可同时生效，互不替代。
