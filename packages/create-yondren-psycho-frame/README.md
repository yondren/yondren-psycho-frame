# create-yondren-psycho-frame

[yondren-psycho-frame](https://www.npmjs.com/package/yondren-psycho-frame) 的
npm create 入口包。`npm init yondren-psycho-frame` / `npm create yondren-psycho-frame`
会解析到本包并转发参数给核心包的 `init` 命令。

```sh
npm create yondren-psycho-frame@latest my-project
```

等价于 `npx yondren-psycho-frame init my-project`。命令、配置与模板说明见
[yondren-psycho-frame](https://www.npmjs.com/package/yondren-psycho-frame)。
